# postAIjob - Projekt

## Co to jest
Platforma do szukania pracy wspierana przez AI (postAIjob), budowana na bazie szablonu **TailAdmin Next.js v2.3.0**.

## Stack
- Next.js 16 + React 19
- Tailwind CSS V4
- TypeScript

## Dev server
```bash
npm run dev
# Uruchamia na http://localhost:3000 (lub kolejnym wolnym porcie)
```

## Skad pochodzi baza
Sklonowane z: https://github.com/TailAdmin/free-nextjs-admin-dashboard
